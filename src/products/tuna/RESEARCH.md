## Independent-review clarifications
- `consolidate.go:187–191` validates that proposed old text occurs exactly once and cites a kept preference; whether the edit is related/evidence-supported remains a model judgment. The website therefore makes no unconditional unrelated-text preservation guarantee.
- `analyzer.go:233–241` sends active preferences and complete queued event objects (including available context/cwd metadata); `consolidate.go:116` also sends existing shared instructions. `mcp.go:31–49` describes the remember restriction in instructions; the handler does not verify user/skill direction.
- The original mechanical revision displayed #12/#13's supporting history. Subsequent explicit user feedback rejected that form's complexity. The current example retains labelled Session 1/2 supporting quotes in a secondary disclosure, explains separate evidence on supersession, and removes IDs/categories/confirmation forms from the primary story.
- Manual macOS installation first requires `grep` to find the selected release checksum entry, then pipes it to `shasum -a 256 -c -`, chained with `&&` before mkdir/install. A missing entry prints a recovery message and returns failure. The documented Linux substitution is `sha256sum -c -` plus the correct Linux asset name. Requiring grep success also avoids checksum utilities that return success on empty input.
